VOTRE STUDIO, SUR ANDROID

PocketCut dans votre poche.

Montez vos vidéos dans l’application Android, avec vos projets enregistrés sur votre appareil.

Télécharger l’APK AndroidVersion 2.2.3 · Test 3 · Android 10 ou plus récent
  1. Ouvrez le fichier APK téléchargé et suivez les indications d’Android pour l’installer.
  2. Déjà installé ? Choisissez Mettre à jour, sans désinstaller l’ancienne version, afin de conserver vos projets.
  3. Les prochaines versions seront proposées dans l’application. Vous pouvez aussi utiliser le bouton ↻ Mises à jour. Android vous demandera de confirmer l’installation.

Vos projets Chrome et ceux de l’APK ont des stockages séparés. Pour transférer un montage : Projets → Sauvegarder le projet dans le navigateur, puis ouvrez le fichier .pocketcut dans l’application.

Le montage fonctionne sur l’appareil. Une connexion Internet reste nécessaire pour les mises à jour et certains modèles IA.
